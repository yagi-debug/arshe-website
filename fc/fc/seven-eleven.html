1. FC本部情報


会社名: 株式会社セブン-イレブン・ジャパン

親会社: セブン&アイ・ホールディングス（東証プライム上場）

創業: 1974年

本社所在地: 東京都千代田区二番町8番地8

代表電話: 03-6238-3711


セブン-イレブン・ジャパンは日本のコンビニエンスストア業界で圧倒的なシェアを占める最大手企業。全国で21,734店舗を展開（2026年3月末現在）し、日本国内コンビニの約43%を占める。



2. FC加盟条件

  • 2名以上での加盟（夫婦、親子、兄弟姉妹など血縁三親等以内）
  • 営業に専念できる経営体制

    本部サポート（経費負担）

  • 水道光熱費の80%を本部が負担
  • 不良品原価相当額の15%を本部が負担

    • 最低保証制度

  • Cタイプ24時間営業: 年間オーナー総収入1,700万円を保証
  • Aタイプ24時間営業: 年間オーナー総収入1,900万円を保証
  • ※最低保証はオーナー総収入の保証であり、人件費・不良品等の営業費控除後の利益保証ではない


    • 4-2. 投資回収期間


  • Cタイプ（初期投資260万円）: 年間手残り504万円の場合、**約6ヶ月～1年で初期投資を回収**可能と試算される
  • ただし初期投資が低い分、チャージ率が高く長期的な収益性ではAタイプに劣る
  • Aタイプは自己物件の取得・改装費用を含めると数千万円規模になるため、回収に**5年以上**を要する可能性がある
  • セブン本部は「低投資のストックビジネスだから早期投資回収が可能」と訴求している
  • コンビニFC全般として、10年以上経営を続けられる確率は全体の約3割との指摘もある

    • 出典: https://fc-review.com/32/ / https://next-business.co.jp/brand/31712/



    4-3. 損益分岐点


  • コンビニの営業利益率が2～5%程度のため、**月商ベースで1,200万～1,500万円程度が損益分岐ライン**と推定される
  • 日販40万円（月商1,200万円）を下回ると赤字リスクが高まる
  • 最低保証制度があるため、Cタイプでは本部が差額を補填するが、保証はオーナー総収入であり人件費等は自己負担

    • 出典: https://www.fc-convenience.com/archives/175

    • 6. 評判（口コミ傾向）


    ポジティブ評価

  • 高い年収が期待できる（600万～900万円レンジ）
  • 本部による充実した経費サポート（光熱費80%負担等）
  • 日本最大級のブランド力と集客力
  • 最低保証制度による収入下限の担保
  • 既存店舗引き継ぎオプションあり

    • ネガティブ評価・懸念点

  • ロイヤリティ率（43～74%）が業界内で最高水準。経営を圧迫しやすい
  • 24時間営業による労働負荷・人員確保コストが大きい
  • 在庫管理・廃棄ロスのリスク（オーナー負担）
  • 期間限定商品の販売ノルマあり（売れない場合は自腹購入リスク）
  • 本部の高い経常利益率（31.6%）に対してオーナー収益との格差を指摘する声
  • 中途解約時の違約金が撤退コストを高める
  • 契約期間15年という長期拘束


    • 7. 競合比較


    コンビニ業界における競争構図

  • セブンイレブン: 21,734店（シェア43%）
  • ファミリーマート: 16,415店（シェア33%）
  • ローソン: 14,600店程度（シェア29%以下）

    • セブンイレブンが圧倒的トップシェアを維持。ロイヤリティ率は他社比較で高めの水準。



    8. リスク・懸念点


    撤退条件（中途解約・違約金）


    項目内容
    契約期間15年
    中途解約違約金本部フィーの1～6ヶ月分（開店3年未満の脱サラモデルで約850万円が目安）
    違約金免除の可能性日販30万円以下を6ヶ月以上継続した場合 / 90日以上就業不能（うつ病等）の場合
    加盟者・補助者の死亡・離婚時解約金規定なし（無料になる可能性）
    本部側からの契約解除信頼関係破綻等を理由に解除し、約1,200万円の違約金を請求した事例あり
    交渉余地契約書上の違約金を実際には請求しないケースも報告されており、SVへの相談が重要

    出典: https://blog.yam5.com/archives/3194 / https://www.corporate-legal.jp/news/4738 / https://www.bengo4.com/c_18/n_9269/


    失敗パターン（よくある廃業・苦戦の原因）


    1. 人手不足による過労: 24h営業でシフトに穴が開くとオーナー自ら入らざるを得ない。家族総出で店に立つケースも多数報告されている

    2. 廃棄ロスの累積: 弁当・惣菜等の廃棄はオーナー負担。見切り販売を本部が制限してきた経緯あり

    3. ドミナント出店による売上減: 近隣に同チェーン新規出店され、既存店の売上が激減するパターン

    4. 人件費高騰への対応困難: 最低賃金上昇に対しチャージ率は固定のため、人件費増がそのまま利益圧縮に直結

    5. 本部サポートの実態とのギャップ: 契約時の説明と実運営でのフォロー体制に乖離があるとの指摘

    6. 精神的な疲弊: 2022年にセブンイレブン店長（38歳）が過労を背景に自死し、労災認定された事例が報道されている


    出典: https://fc-sidejob.com/konbinikeiei/ / https://president.jp/articles/-/32282 / https://www.grid-based.com/?p=1441 / https://www.mag2.com/p/money/798181


    本部トラブル（訴訟・公正取引委員会指摘）


    1. 24時間営業強制問題（2019年～）: 東大阪のオーナーが人手不足で時短営業に踏み切ったところ、本部が1,700万円の請求と契約解除を通告。大阪地裁は本部側の契約解除を有効と認定（控訴審でも敗訴）

    2. 公正取引委員会の警告（2020年）: 24時間営業の強制やドミナント出店がFC本部による「優越的地位の濫用」に当たる可能性があると指摘

    3. 見切り販売妨害事件: 公正取引委員会がセブンイレブンの見切り販売制限行為を不公正な取引方法と認定。加盟店による損害賠償請求訴訟あり

    4. 高額違約金問題: 鹿児島の元オーナーが九州豪雨災害時のトラブルで約1,200万円の違約金を請求され、公取委に調査を申し入れた事例

    5. 労働者性の否定（最高裁）: セブンイレブン店主らの団体が労働組合法上の労働者性を主張したが、最高裁が否定

    6. ドミナント出店問題: 既存店の至近距離に新規出店され売上が激減する事例が多数。公取委は「優越的地位の濫用」の可能性を指摘


    出典: https://www.ktv.jp/news/feature/220623-1/ / https://www.corporate-legal.jp/news/4738 / https://www.corporate-legal.jp/news/1818 / https://toyokeizai.net/articles/-/278151
