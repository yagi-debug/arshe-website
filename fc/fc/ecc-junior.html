    • 4. 収益の実態


    ホームティーチャーの収入モデル

  • **初期段階（1年目）**: 月収約7万円程度（年間100万円未満）
  • **安定期**: 月収約18万円程度（確立された教室の場合）
  • **生徒数による増減**: 1生徒が複数教科受講の場合、生徒数カウントが増加
  • **安定化目安**: 生徒10～15名以上で月収が家計補助レベルに
  • **最大配分率**: 生徒数多い場合、年2回の配分調整金で最高77%まで上昇

    • 月謝配分率の仕組み

  • **基本配分率**: 生徒の月謝の50%
  • **配分調整金**: 生徒数に応じて年2回支給
  • **スケーリング構造**:

    • - 少数生徒（1～5名） → 50%

    - 中程度生徒（6～10名） → 60～70%

    - 多数生徒（15名以上） → 最大77%


    運営費の実態

  • **自宅開設型**: 広告宣伝費が主体
  • **貸会場型**: 家賃（テナント型）+ 広告宣伝費
  • **隠れた費用**: 電気代、教材補充、生徒宅対応時の交通費等

    • 実例：15名の生徒で月赤字

  • 月謝（月額5,500円×15名） = 82,500円
  • 本部配分（50%）= 41,250円
  • 支出（備品購入、電気代、交通費等） = 50,000円程度
  • **月間赤字**: 約9,000円
  • **年間赤字**: 約108,000円

    • 8. 投資回収期間・損益分岐点


    投資回収期間


    初期投資パターン初期投資額月額利益回収期間
    自宅開講型（最小）5～10万円5～10万円（赤字の可能性）1～2年（不確定）
    自宅開講型（標準）20～30万円10～20万円1.5～3年
    テナント開講型本部補助金280万円支給あり30～50万円6～10年以上

    実態：

  • **1年目**: 月収7万円程度 → 年収84万円（初期投資未回収）
  • **2～3年目**: 月収15～20万円に成長 → 初期投資の回収開始
  • **4～5年目以降**: 安定期（月収20万円程度）

    • 注記:

    回収期間は「生徒集客の成功」に極度に依存。生徒集客に失敗すれば回収不可能。


    損益分岐点


    指標金額
    最小生徒数（損益分岐）約12～15名
    月額固定費（自宅型）3,000～5,000円（広告宣伝費）
    月額固定費（テナント型）10～20万円（家賃）

    • 11. 撤退条件・契約解除・違約金


    クーリングオフ制度


    項目内容
    クーリングオフ期間契約日から**8日以内**
    返金対象入学金、授業料、教材費の全額
    手続き本部に書面で通知

    注記:

    ECCジュニアは特定商取引法の「特定継続的役務提供」に該当するため、クーリングオフ制度が適用される。


    中途解約・違約金


    項目内容
    中途解約違約金**要資料請求**
    違約金上限（法的）「提供役務価格と5万円または残額の20%のいずれか低い額」の合計
    解約通知期限**要資料請求**（通常1～3ヶ月前）
    契約期間**要資料請求**

    実態：

    中途解約に関する具体的な情報は、ホームティーチャーからの口コミでも「違約金について不明」という報告が多い。本部に直接確認が必須。


    撤退シナリオ


    1. 生徒集客失敗（初期段階 3～6ヶ月）

    - 見込み生徒が集まらない

    - 月収数万円で赤字拡大

    - 解約検討 → クーリングオフ対象（8日以内なら全額返金）

    - 8日以降の解約 → 違約金発生可能


    2. 経営継続不可（1～2年目）

    - 生徒数が増えない → 月10名未満で赤字継続

    - 広告費を投下しても成果なし

    - 解約申請 → 違約金が発生する可能性

    - 実例：「違約金が発生する」という報告あり


    3. 既存生徒の大量退会（2年目以降）

    - 講師の交代、病気、家庭の事情で生徒が去る

    - 講師側が体調不良で教えられなくなる

    - 撤退検討 → 契約条件により違約金有無判定

    • 12. 失敗パターン・対策


    よくある失敗パターン


    パターン原因結果対策
    **生徒集客失敗**自宅型では認知度ゼロ、広告効果不十分初年度月収数万円のまま、赤字継続広告戦略を事前に綿密に立てる。本部の生徒紹介制度の活用
    **経営費用の甘い見積もり**広告費、交通費、電気代を過小評価15名の生徒でも赤字既存ホームティーチャーに実際の支出を直接確認
    **講師の適性ミス**英語教育経験がない。教えるスキルがない生徒が成果を感じず退会 → 新規生徒集客も失敗教育研修を十分受講後、小規模テスト運営で適性確認
    **生徒宅対応負担**ホームティーチャー制度の想定外の業務体調不良、ストレス蓄積 → 休講・撤退契約前に詳細な業務内容（家庭訪問頻度、保護者対応等）を確認
    **講師交代による生徒流出**子育て、病気、転居で講師が交代既存生徒がついてこない → 新規生徒が来ない長期継続可能な体制設計を事前に確認
    **廃業予定地でテナント開講**コロナで借会場が閉鎖、一年半で生徒ゼロ違約金＋赤字で撤退不可能テナント選定時に長期継続の可能性を確認
    **初期の月収期待値ミス**「月20万円稼げる」という営業説明を信じた実際は月7万円 → 失望し続きモチベーション低下1年目月収7万円程度という実態を理解した上で加盟判断
    **負債化による撤退困難**初期投資30万円＋違約金＋機器返却費で数十万の赤字撤退しても負債が残るクーリングオフ期間内に決断する or 本部と分割返金交渉

    ECCジュニアの構造的課題


    1. 生徒集客が完全に加盟者任せ

    - 本部は「募集応援費5万円支給」だけ

    - その後の広告・営業は自分でやる必要あり

    - 営業スキルがない者は必ず失敗


    2. 1年目のキャッシュフロー危機

    - 初期投資30万円＋月額赤字 → 資金枯渇リスク

    - 2年目まで生徒が増えない場合、撤退を強制される


    3. クーリングオフ後の選択肢がない

    - 8日以降の中途解約は違約金有り

    - 違約金の金額が不透明なため、撤退判断が難しい


    成功する加盟者の特徴


  • 英語教育経験あり（元英語講師、英語教師OB等）
  • 営業・集客スキルが強い（営業職経験者等）
  • 地域コミュニティとの人脈が豊富
  • 初期赤字2～3年を覚悟できる資金力がある
  • 継続可能な人生設計（子育て終了予定、転職予定なし等）
