4. 収益の実態


商品・顧客単価


  • **シーズナル商品の強さ**: スフレパンケーキが定番商品として高い訴求力を持ち、季節限定メニューが定期的にリリース
  • **顧客単価**: スペシャリティコーヒー + フードの組み合わせで、競合他社（スタバ、コメダ）と比較して高単価（1,500～2,500円程度）
  • **客層**: ビジネスマン、シニア層、大学生・カップル層（近年増加）

    • 採算指標（カフェ業界一般）


  • **原材料費率**: 売上の30%以内が目安
  • **人件費率**: 売上の30%以内が目安
  • **FL比率**（原材料費+人件費）: 55～60%以内が目安
  • **目標営業利益率**: 10%前後

    • ロイヤリティ体系と採算性


  • **ロイヤリティ**: 座席数×月額1,500円

    • - 100席の店舗 = 月額15万円（売上300万円の店舗で営業利益率30万円として5%に相当）

    - 80席の店舗 = 月額12万円

  • **坪効率**: 坪効率が悪い立地ではロイヤリティが採算を圧迫する構造

    損益分岐点（月額売上）


    項目金額
    月額固定費（目安）150～200万円

    月額固定費（合計）150～200万円
    **必要月売上（利益率10%の場合）****1,500～2,000万円**
    平均客単価1,800円
    **必要日販売客数****833～1,111名/日**

    解釈:

  • 月売上1,500万円以上で損益分岐点を超える
  • 日販売客数で833～1,111名（営業時間10時間として約83～111名/時）が必要
  • 高級カフェのため、通常の近隣カフェより客数は少ないが、客単価が高い
  • 立地が悪い場合、日販売客数が確保できず赤字化する

    良好立地の場合:

  • 初期投資: 5,000万円
  • 年間利益: 1,000万円 = 5年で回収

    • 競争激化地域の場合:

  • 初期投資: 5,000万円
  • 年間利益: 300～500万円 = 10～15年で回収（困難）

    • 8. リスク・懸念点


    1. 市場飽和: カフェ業界は成熟市場、既に競争が激化している

    2. 直営化傾向: フランチャイジー37店舗のみ（全278店舗中）- 本部が直営重視に切り替え

    3. 加盟店破産の前例: 2022年に北陸フードシステムズが破産（負債27億円）- 新型コロナで売上が半減

    4. 高初期投資: 5,000万円以上の投資に対し、5～7年での回収が必須

    5. 座席数ベースロイヤリティ: 坪効率が悪い立地では経営が困難

    6. 認知度格差: コメダ珈琲に比べて認知率が27ポイント低い（92% vs 65%）

    7. 若年層獲得の課題: 大学生やカップル層へのアプローチが必要だが、限定的



    9. 採用・人材


  • **スタッフ育成体制**: マンツーマン研修で未経験者も対応可能（アルバイト中心）
  • **昇進・昇給制度**: 基本給ベースのマニュアル合格で時給アップ（定着促進）
  • **採用難**: 飲食業全般で人手不足が課題（調査時点で明確なデータなし）
  • **シニア層活用**: 店舗雰囲気がシニア向けであり、シニアスタッフの活用が考えられるが、調査対象外

    12. 失敗パターン・対策


    よくある失敗パターン


    パターン原因結果対策
    **立地選定失敗**都市部郊外や新興地域への出店。競合店（コメダ、スタバ）が近い日販売客数が目標の50%以下 → 月売上1,000万円以下 → 赤字化商業施設内やビジネス街など、ターゲット層の通行量が確保される場所を選定。3ヶ月の客流調査必須
    **過度な設備投資**ロードサイド型で建築工事に3,000万円以上、家具・機器に1,000万円以上投資初期投資が6,000万円を超える。投資回収期間が7年以上に延伸改装費・設備費の詳細見積を事前に複数社から取得。本部の想定コストとの比較
    **人件費の過剰計上**高級カフェのイメージで、経験豊富な店長・スタッフを多数配置人件費が売上の35～40%に達する。月額赤字30～50万円初期段階は最小限の人数で開始。業務効率化で対応。段階的な人員増加計画
    **コロナなどの経営環境悪化**パンデミック、景気悪化で顧客来店減北陸フードシステムズの例：売上13.7億円→7億円（約半減）→ 破産3ヶ月の赤字でも耐えられる自己資金を確保。本部のリスク対応策を事前確認
    **顧客単価の低下**オープン初期は客単価1,800円だが、リピーター獲得のため値下げ競争に走る客単価が1,500円→1,200円に低下。売上30%減少価格ではなく「空間体験」「質」で差別化を徹底。値下げに頼らない経営方針
    **認知度の不足**コメダ珈琲（認知率92%）と比べ、星乃珈琲（認知率65%）は地域依存郊外では「何の店？」という認識。集客困難都市部中心部への出店。SNS・地域メディアでの認知構築に投資
    **本部サポート不足（直営化傾向）**本部が直営重視に転換。フランチャイジーへのサポート削減マーケティング支援、スーパーバイザー派遣が減少。孤立化契約前に、サポート内容・頻度を具体的に確認。書面で約束させる

    北陸フードシステムズ破産の教訓


    事例:

  • 2022年1月、北陸フードシステムズが負債27億円で破産申請
  • 新型コロナで売上が2020年度13.7億円 → 2021年度7億円に半減
  • フランチャイジー経営による多店舗展開の脆弱性が顕在化

    • 学ぶべき点:

    1. 外食業は「不可抗力」に強くない（パンデミック、景気悪化）

    2. 複数店舗の一括経営は、1店が失敗すると全体を巻き込む

    3. 本部のリスク対応策（テナント賃料補助、ロイヤリティ減免など）の有無が生死を分ける


    星乃珈琲で成功するための必須条件


    1. 立地: 都市部商業施設内 or ビジネス街（駅前、オフィス街）

    2. 資金力: 初期投資5,000万円 + 3年間の赤字補填1,000万円 = 最低6,000万円の自己資金

    3. 経営経験: 外食FC経営経験者が有利。飲食業界未経験者は困難

    4. 運営体制: 経営責任者が常に店舗に関与可能な体制

    5. 市場理解: 高級カフェ市場の顧客心理を理解している
