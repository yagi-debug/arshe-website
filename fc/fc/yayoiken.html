やよい軒 — FC調査データ

最終更新: 2026-04-03（データ収集日: 2026-04-03）



1. FC本部情報


会社名: 株式会社プレナス

上場状況: 2023年2月24日に東証プライム市場を上場廃止（MBOにより非公開化）

創業: 1976年（「やよい軒」ブランドは1990年代に確立）

主要事業: 外食チェーン運営（「やよい軒」定食、「ほっともっと」弁当）

店舗規模: プレナスグループで約2,500店（ほっともっと）+ 600店（やよい軒）を国内外で展開


MBOの経緯: 2022年10月、創業家の資産管理会社「塩井興産」がTOBを実施。1株2,640円で約89%まで買い進め、2023年1月の臨時株主総会で非上場化を承認。「短期的な利益にとらわれず中長期的に企業価値を向上させるため」と説明。


プレナスは飲食FC業界でも有数の大手企業。やよい軒は定食チェーンとして認知度が高く、特に中高年層からの信頼厚い。元々「ほっかほっか亭」の加盟店から独立した経緯を持つ。


出典: https://www.nikkei.com/article/DGXZQOJC148CD0U2A011C2000000/ / https://www.data-max.co.jp/article/61542



2. FC加盟条件


加盟制度は3種類


1. ユニットFC制度（主力プラン）

  • プレナスが建物・設備・運営システムを全て用意してオーナーに貸与
  • 1号店は原則として既存店舗（直営の黒字店）を引き継ぐ（リスク低減）
  • 複数店舗経営意欲のある法人向け

    • 2. 経営委託制度（パートナーチェーン）

  • 社員として開業するため自己資金0円で加盟可能
  • 1年間の委託契約で直営店の経営を受託
  • 委託料の支給を受ける代わりに毎月店舗使用料を支払う
  • 半年間の研修+経理サポート付き
  • 費用は給与から天引きされる形で精算
  • 独立前のステップとして活用される。契約は本人の意思次第で延長可

    • 3. 通常FC制度

  • 自己資金で土地建物から手配する従来型
  • 開業費用: 約8,000万円前後

    • 基本資格（ユニットFC）

  • 法人またはこれに準ずる事業組織
  • 創業3期連続黒字
  • 自己資本比率20%以上（目安）
  • 複数店舗経営意欲のある法人推奨

    • 初期投資総額（ユニットFC）


    項目金額
    加盟金500万円
    保証金200万円
    諸費用120万円
    **合計****820万円**
    再契約料（5年後更新時）25万円
    2店舗目以降の加盟金300万円（減額制度あり）

    ※通常の自己資金開業では約8,000万円かかるところ、ユニットFC制度により約1/10のコストで開業できる。経営委託制度なら自己資金0円。

    ※店舗の設備等の修繕費は本部が負担。


    出典: https://www.plenus.co.jp/franchise/yayoi/system/unit_fc.html / https://www.fc-mado.com/detail/2176 / https://fcch.co.jp/brand/1437

    店舗修繕費本部負担

    5. サポート体制


    研修制度

  • 開業前研修: 30日以上（1か月半程度）
  • 内容: レストラン経営ノウハウ、接客、調理技術、ホール・キッチンオペレーション、電話応対、店舗管理、金銭原価管理

    • 開業後サポート

  • エリアマネージャーによる定期訪問
  • 経営アドバイス
  • 給与計算などの財務サポート
  • 販売促進支援
  • 物流システム管理

    • 追加サポート

  • 2店舗目以降の加盟金減額制度（500万円→300万円）
  • 複数店舗経営支援体制


    • 6. 評判（口コミ傾向）


    ポジティブ評価

  • 初期投資が比較的低い（開業総額820万円 / パートナーチェーンなら0円）
  • ロイヤリティ率が低水準（2～6%、業界平均より有利）
  • 既存店舗引き継ぎで開業リスク低減（黒字直営店を引き継げる）
  • 本部による充実した研修体制（30日以上）
  • 複数店舗展開しやすい体制整備
  • ブランド力が高い（定食屋として認知度高い）
  • 本部マネージャーとのパートナーシップ関係が良好という評価
  • 店舗修繕費が本部負担

    • ネガティブ評価・懸念点

  • 飲食業界の労働条件の厳しさ（人員確保、長時間営業）
  • 食材仕入・原価管理の複雑性
  • 市場飽和（都市部での出店困難）
  • 顧客回転率に依存した経営
  • 仕組みが構築されているため独自色を出しにくい（フロンティア精神が強い方には不向き）
  • 店舗によって味のばらつきや提供時間の差がある
  • 収益を上げるにはオーナー自身も業務に長く従事する必要がある
  • Yahoo知恵袋等では「加盟店は生かさず殺さず」「かなりの激務」との声も

    • 出典: https://www.ninkitaurant-fc.com/restaurant/yayoiken.html / https://www.tapnow.jp/yayoiken-review/ / https://detail.chiebukuro.yahoo.co.jp/qa/question_detail/q14172497274



    7. 競合比較


    飲食FC（定食・和食系）との比較

  • やよい軒: ロイヤリティ2～6%、初期費用820万円
  • 他の大型定食チェーン: 初期投資1,000～1,500万円、ロイヤリティ5～8%が多い
  • やよい軒は初期投資・ロイヤリティ共に競争力あり

    • ブランド力: 定食チェーンで上位2～3社のうち1つ

    本部決算: 2019年2月期のやよい軒事業は12億円の黒字（ただし「ほっともっと」事業は赤字傾向の時期あり）



    8. リスク・懸念点


    撤退条件（中途解約・違約金）


    項目内容
    契約期間5年間（セブンイレブンの15年と比べ大幅に短い）
    更新5年毎に意思確認を行い再契約（再契約料25万円）
    中途解約違約金やよい軒固有の違約金額は公開情報で確認できず
    一般的なFC違約金の相場ロイヤリティの数ヶ月分～数年分が一般的
    合意解約本部との合意により違約金なしで解約できるケースもある（一般論）

    ※5年契約のため、セブンイレブン（15年）やコメダ珈琲（10年）と比較して拘束期間が短く、撤退の柔軟性は高い。


    出典: https://kigyobengo.com/media/useful/1338.html / https://entrenet.jp/magazine/13573/


    失敗パターン（よくある廃業・苦戦の原因）


    1. 人手不足による長時間労働: 飲食業全般の課題。調理スタッフ確保が特に困難

    2. 原材料費高騰への対応: 食材原価の上昇がそのまま利益を圧縮。メニュー価格は本部主導のため独自に値上げしにくい

    3. 立地依存リスク: ロードサイド店は近隣の競合飲食店出店や道路事情の変化で集客が激変する可能性

    4. オーナーの現場依存: 経営者でありながら現場にも立つ必要があり、マネジメントに集中できない構造

    5. 具体的な廃業事例: やよい軒固有の大規模な失敗事例・訴訟事例は調査範囲では見当たらず。セブンイレブンのような深刻な本部トラブルは報告されていない


    出典: https://www.fc-mado.com/useful/yayoiken-fc/ / https://www.grid-based.com/?p=1387


    本部トラブル


  • やよい軒固有の大規模な訴訟・公正取引委員会からの指摘は調査範囲では**確認されていない**
  • プレナス全体としては、「ほっともっと」事業で190店閉店（2019年頃）など経営判断が報道されたが、やよい軒FCオーナーとの深刻なトラブルは見当たらない
  • MBOにより非上場化したため、2023年以降は経営情報の透明性が低下している点は留意が必要
  • Yahoo知恵袋等で「プレナスだけが儲かるシステム」との匿名投稿はあるが、訴訟や公的機関の指摘には至っていない

    • 出典: https://www.mag2.com/p/money/746909 / https://www.data-max.co.jp/article/61542


    経営リスク

  • 食材原価変動の影響（原油・農産物価格）
  • 人員確保・人件費負担（特に調理スタッフ）
  • 食品衛生管理の厳格性
  • 外食需要の変動（景気・トレンド依存）

    • 地域・立地リスク

  • 都市部での出店競争激化
  • 駅前・商業施設内の高テナント料
  • 地方部での需要不確実性

    • 事業継続リスク

  • 既存店舗引き継ぎは限定的（全新規オーナーが対象ではない可能性）
  • 本部の出店戦略に依存
  • MBO後の非上場化により経営情報の外部監視が低下

    • 10. SNS・ブランド力


    ブランド力

  • 定食チェーンとしての全国認知度: 高い
  • 中高年・会社員・学生を中心に利用層広い
  • メディア掲載実績: 定食チェーンランキングで常に上位

    • SNS・デジタルマーケティング

  • やよい軒公式SNS（Twitter、Instagram）
  • 食べログ・ぐるなびなどの飲食情報サイトでの露出
  • 店舗レベルでのSNS活動: 詳細不明（本部推奨あるが強制ではない）


    • 11. 市場環境


    外食業界動向

  • 定食・和食の需要は安定的（ファミリー層・高齢者）
  • 回転寿司・カフェなど他業態との競争激化
  • デリバリー・テイクアウトの需要拡大
  • 原材料費・人件費上昇圧力

  • 価格帯の工夫（顧客満足度維持）
  • 新メニュー開発
