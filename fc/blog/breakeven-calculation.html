フランチャイズの損益分岐点 — 自分で計算する方法と注意点

フランチャイズへの加盟を検討するとき、FC本部が提示する「モデル収支」は参考になる一方、「自分の店舗でも同じ利益が出るのか」を自分で検証することが不可欠です。その検証の中心となるのが損益分岐点（BEP：Break Even Point）の計算です。

損益分岐点とは、利益がちょうどゼロになる売上高のことです。この金額を上回れば黒字、下回れば赤字になります。本記事では、損益分岐点の計算式・FCにおける具体的な計算例・安全マージンの考え方まで、実務に役立つ形で解説します。

損益分岐点の基本式

損益分岐点売上高の計算式は次の通りです。

```

損益分岐点売上高 ＝ 固定費 ÷ 粗利率

```

それぞれの用語を確認します。

固定費とは

売上の大小にかかわらず毎月一定額発生するコストです。フランチャイズ店舗での主な固定費は以下の通りです。

  • 家賃・共益費
  • 人件費（特に正社員の給与・社会保険料）
  • ロイヤリティ（固定額型の場合）
  • リース料（厨房設備・POSレジ等）
  • 保険料・固定の水道光熱費

変動費とは

売上に連動して増減するコストです。

  • 食材費・原材料費
  • アルバイトの時給（売上に応じてシフト調整する場合）
  • ロイヤリティ（売上歩合型の場合）
  • 決済手数料・消耗品費

粗利率の計算

```

粗利率 ＝ （売上高 − 変動費） ÷ 売上高

```

または

```

粗利率 ＝ 1 − 変動費率

```

FCにおける具体的な計算例

前提条件の設定

以下の数字を仮定して損益分岐点を計算してみます。

| 固定費の項目 | 月額 |

|------------|------|

| 家賃・共益費 | 20万円 |

| 人件費（社員・固定分） | 40万円 |

| ロイヤリティ（固定額型） | 15万円 |

| リース料・その他固定費 | 5万円 |

| 固定費合計 | 80万円 |

変動費率（原材料費・変動的な人件費等の合計）を40%と仮定すると、

```

粗利率 ＝ 1 − 0.4 ＝ 0.6（60%）

```

損益分岐点の計算

```

損益分岐点売上高 ＝ 80万円 ÷ 0.6 ≒ 133万円

```

つまり、月商133万円を超えれば黒字になる計算です。

別パターン：ロイヤリティが歩合型の場合

ロイヤリティが「売上の5%」という歩合型の場合、ロイヤリティは変動費として扱います。

| 固定費の項目 | 月額 |

|------------|------|

| 家賃・共益費 | 20万円 |

| 人件費（固定分） | 40万円 |

| リース料・その他 | 5万円 |

| 固定費合計 | 65万円 |

変動費率：原材料費40% ＋ ロイヤリティ5% ＝ 45%

```

粗利率 ＝ 1 − 0.45 ＝ 0.55（55%）

損益分岐点売上高 ＝ 65万円 ÷ 0.55 ≒ 118万円

```

固定型ロイヤリティのケース（133万円）と比べ、歩合型のほうが損益分岐点が低くなりました。ただし、売上が上がると歩合型のほうがロイヤリティ支払いが増えるため、どちらが有利かは月商の水準によって変わります。

安全マージンの考え方

損益分岐点を計算したら、次に「どれだけ余裕があるか」を示す安全余裕率を確認します。

安全余裕率の計算式

```

安全余裕率（%）＝ （計画売上高 − 損益分岐点売上高） ÷ 計画売上高 × 100

```

計算例

計画売上高を月200万円と仮定した場合（損益分岐点133万円のケース）：

```

安全余裕率 ＝ （200万円 − 133万円） ÷ 200万円 × 100 ＝ 33.5%

```

この場合、売上が計画から33.5%ダウンしても黒字を維持できる計算になります。

安全余裕率の目安

| 安全余裕率 | 評価 |

|-----------|------|

| 30%以上 | 比較的安全な水準 |

| 20〜30% | 注意が必要 |

| 10〜20% | リスクが高い |

| 10%未満 | 危険な水準 |

一般的に安全余裕率が20%を下回ると、売上の少し落ち込みで赤字に転落するリスクがあります。FC本部が提示するモデル収支の月商をそのまま計画値にするのではなく、20〜30%保守的に見積もった場合でも損益分岐点を上回るかを確認することが重要です。

FC特有の計算上の注意点

1. ロイヤリティの扱いに注意

ロイヤリティが固定型か歩合型かで、固定費・変動費の分類が変わります。歩合型は変動費として扱い、粗利率の計算に組み込む必要があります。

また、売上が増えると歩合型ロイヤリティの絶対額も増えるため、「高売上=高利益」という単純な関係にはなりません。

2. 人件費の分類に注意

人件費は「固定的な部分」と「変動的な部分」が混在することが多いです。

  • 正社員の給与・社会保険料 → 固定費
  • 売上に応じてシフトを増減させるアルバイト分 → 変動費

実態に合わせて固定費・変動費を切り分けることで、より正確な損益分岐点が計算できます。

3. 開業初期の特殊コスト

開業初期は広告宣伝費・採用費・研修費が多くかかる場合があります。これらは毎月発生するわけではありませんが、初年度は「特別固定費」として計算に含めることで、実態に近い損益計算ができます。

4. 季節変動の考慮

飲食業や学習塾など、季節によって売上が大きく変動する業態では、月単位ではなく年間トータルで損益分岐点を計算することも重要です。ピーク月の数字だけで判断すると、閑散期の赤字幅を見落とすリスクがあります。

本部のモデル収支との照合方法

FC本部が提示するモデル収支には「モデル店舗」の平均的な数字が記載されています。これを自分の計算と照らし合わせる際のチェックポイントを整理します。

確認すべき項目

  1. 家賃の設定は妥当か：モデル収支の家賃と、候補物件の家賃を比較する。モデル収支の家賃が低すぎれば、実際の損益分岐点はもっと高くなる
  2. 人件費はオーナー自身の労働分が含まれているか：オーナーが現場に入る場合、自身の人件費相当額を計算に入れていないと利益を過大計上している
  3. ロイヤリティの計算が正確か：歩合型の場合、モデル月商に対して何%かを実際に計算して確認する
  4. 広告費・採用費は含まれているか：開業後も継続的にかかる集客コストが抜けていないかを確認する

計算を自分でやる意味

損益分岐点の計算をFC本部任せにせず、自分で行うことには以下の意味があります。

  • 現実的なシナリオを複数試算できる：最良・標準・最悪の3ケースで計算し、最悪でも許容できるかを判断できる
  • 交渉材料になる：家賃・ロイヤリティの設定が高すぎる場合、数字を根拠に交渉しやすくなる
  • 借入計画に活用できる：金融機関への事業計画提出時に信頼性の高い数字を示せる

FAQ

Q1. 損益分岐点の計算は難しいですか？専門知識が必要ですか？

A. 基本の計算式はシンプルであるため、表計算ソフト（ExcelやGoogleスプレッドシート）があれば誰でも計算できます。難しいのは「どの費用を固定費・変動費に分類するか」という判断部分です。不安であれば中小企業診断士や税理士に相談しながら計算することをお勧めします。初回相談は無料の場合も多く、開業前の数字確認は専門家の意見を取り入れることが有効です。

Q2. 損益分岐点は開業前に正確に計算できますか？

A. 完全に正確な計算は難しく、実際に営業を始めて初めてわかることも多いです。特に売上は開業してみないとわかりません。そのため、開業前の計算は「保守的な前提で計算する」ことが重要です。売上は本部のモデル収支より20〜30%低く見積もり、コストは高めに見積もる「悲観的シナリオ」でも事業が成立するかを確認することが推奨されます。

Q3. 損益分岐点を下げるにはどうすればいいですか？

A. 損益分岐点を下げるには「固定費を減らす」か「粗利率を上げる」かの2つのアプローチがあります。FCの場合、ロイヤリティや標準仕入れ価格は自由に変更できないことが多いため、主なアプローチは固定費の削減です。具体的には、物件の家賃交渉・オーナー自身が現場に入ることでの人件費削減・設備リース料の見直しなどが挙げられます。ただし、コスト削減が運営品質の低下につながらないよう、バランスに注意することも必要です。
